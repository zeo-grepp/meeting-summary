# meeting-summary

회의를 녹음하면 회의록이 나옵니다. 메뉴바 앱 하나로 녹음·전사·요약을 다 합니다.
전사는 이 맥에서(WhisperKit) 돌고, 요약만 Claude API로 나갑니다.

Apple Silicon Mac, macOS 26 이상에서 동작합니다. Python도 clone도 필요 없습니다.

## 설치

**1. 앱을 받습니다.**

[Releases](https://github.com/zeo-grepp/meeting-summary/releases)에서 **`app-v`로 시작하는**
가장 최근 zip을 내려받습니다. `script-v`는 Python 파이프라인을 따로 깔아야 하는 다른
앱이라 이 절차와 맞지 않습니다.

풀어서 `/Applications`에 넣고 한 줄 실행합니다.

```sh
xattr -d com.apple.quarantine /Applications/MeetingAssistant.app
```

이 줄이 필요한 이유는 Apple Developer ID 인증서가 아직 없어서입니다
([#6](https://github.com/zeo-grepp/meeting-summary/issues/6)). 인증서가 생기면 없어질
단계입니다. 안 돌리면 "손상되었다"며 열리지 않습니다.

**2. 설정을 채웁니다.**

메뉴바 마이크 아이콘 → **설정…** (Dock에는 안 뜹니다)

| 항목 | 넣을 것 |
|---|---|
| 녹음 저장 위치 | 회의록을 모아둘 폴더. 하위에 `recordings/`, `transcripts/`, `summaries/`를 앱이 만듭니다 |
| 요약 (Claude API) | API 키. 사내 게이트웨이를 쓰면 **주소**와 **모델**도 같이 채웁니다. 비워 두면 공개 API로 갑니다 |
| 감시할 앱 (선택) | 회의에 쓰는 통화 앱. 그 앱이 마이크를 잡으면 "녹음할까요?" 알림이 옵니다 |
| 노션 업로드 (선택) | 토큰과 회의록 DB id. 비워 두면 로컬 `.md`까지만 만듭니다 |
| 전사 용어 보정 (선택) | 자꾸 잘못 받아써지는 팀·서비스 이름을 쉼표로 적습니다 |

키와 토큰은 Keychain에만 저장합니다. **연결 테스트**를 눌러 미리 확인하세요 — 회의가
끝난 뒤 5분 기다려서 키가 틀렸다는 걸 알게 되는 일을 막습니다.

**3. 권한을 허용합니다.**

처음 녹음할 때 마이크와 화면·시스템 오디오 녹음 권한을 물어봅니다. 화면 녹음 권한은
허용한 뒤 앱을 한 번 재시작해야 붙습니다. 알림을 켜려면 알림 권한도 따로 허용합니다.

## 쓰기

메뉴바에서 **녹음 시작** → 회의가 끝나면 시간 표시를 눌러 **녹음 종료**.
전사와 요약이 이어서 돌고 끝나면 알림이 옵니다. 1시간 회의면 몇 분 걸립니다.

**첫 전사에서만** 음성 인식 모델 약 1.5GB를 내려받습니다. 그동안은 진행이 멈춘 것처럼
보입니다. 두 번째부터는 없는 단계입니다.

결과는 2번에서 고른 폴더에 쌓입니다.

```
recordings/   녹음 .m4a
transcripts/  녹취록 .txt
summaries/    회의록 .md
```

녹음은 화면 전체 소리와 마이크를 함께 받습니다. 어느 앱에서 회의가 열리든 잡힙니다.
감시할 앱은 알림을 띄울 조건일 뿐이고, 녹음 범위와는 관계없습니다.

## 잘 안 될 때

| 증상 | 원인 |
|---|---|
| 앱이 "손상되었다"며 안 열림 | 1번의 `xattr` 줄을 안 돌렸습니다 |
| "Claude API 키가 설정되지 않았습니다" | 설정의 API 키가 비었습니다. 녹취록은 `transcripts/`에 남습니다 |
| 연결 테스트가 404 | 게이트웨이 주소가 틀렸습니다. 끝의 `/v1`은 있어도 없어도 됩니다 |
| "Claude가 회의록을 반환하지 않았습니다" | 녹취록에 회의 내용이 없어 모델이 요약을 거절한 경우입니다. 짧은 테스트 녹음에서 납니다 |
| 앱 소리가 녹음에 안 들어감 | 화면 녹음 권한을 허용한 뒤 앱을 재시작하지 않았습니다 |
| 회의 감지 알림이 안 옴 | 감시할 앱이 비었거나, 알림 권한이 꺼져 있습니다 |
